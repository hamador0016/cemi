# Security policy

Cemí stores other people's secrets, so security reports come first.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting
("Security" tab → "Report a vulnerability") on this repository. Include the version
(`cemi --version`), your operating system and the steps to reproduce.

You will get an answer within a week. Fixes for confirmed issues are released as soon as
possible, and the report is credited unless you prefer otherwise.

## Scope

What Cemí protects against, and what it does not, is described in
[docs/threat-model.md](docs/threat-model.md). Issues outside that model are still welcome.

## Supported versions

Only the latest release gets security fixes while Cemí is below 1.0.
